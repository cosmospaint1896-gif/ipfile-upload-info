처리하는 정보와 목적

Google OAuth 인증정보(액세스·갱신 토큰), 연결 채널의 식별정보·이름, 영상 식별정보·제목·설명·표지·공개 및 예약 상태를 처리합니다. 운영자가 선택한 영상 업로드, 채널 확인, 예약 중복 방지와 실행 결과 확인에 사용합니다. Google 계정 비밀번호는 수집하지 않습니다.

저장과 보호

컴퓨터에서 실행하는 경우 인증정보는 운영자의 Windows 계정으로 암호화해 보관합니다. GitHub Actions 실행을 선택한 경우 운영자가 인증정보를 GitHub의 암호화된 저장소 비밀값으로 등록하여 해당 실행에 사용합니다. 실행 방식에 따라 파일 위치와 접근 권한은 운영자가 관리합니다. 영상·작업 결과 기록은 운영자의 제작 파일 또는 자동화 저장소에 보관될 수 있습니다. 인증정보는 공개 사이트나 실행 보고서에 게시하지 않습니다.

이용·공유 제한

Google 사용자 데이터는 설명한 채널 운영 기능에만 사용합니다. 판매하거나 광고 타기팅에 이용하지 않으며, 범용 AI 모델 학습용으로 제공하지 않습니다. 업로드 요청·영상은 YouTube로 전송됩니다. 운영자가 GitHub Actions를 선택하면 실행에 필요한 데이터가 GitHub에서 처리됩니다. Google API를 통해 받은 정보의 이용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 준수합니다.

보관 기간과 삭제

인증정보는 운영에 필요한 동안 유지합니다. 운영을 중단하면 로컬 암호화 인증 파일과 등록한 GitHub 비밀값을 삭제합니다. 업로드 결과·작업 기록은 운영자가 필요한 보관 기간을 정하고 해당 파일을 삭제할 수 있습니다. 로컬 기록 삭제나 권한 철회만으로 YouTube에 이미 업로드된 영상이 삭제되지는 않습니다.
